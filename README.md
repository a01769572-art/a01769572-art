## About

I build **AI, data, and software products** that turn complex information into reliable decisions. My work spans reproducible machine-learning systems, automated ETL and data-quality workflows, full-stack web applications, executive analytics, and product strategy.

As a dual-degree student in **Marketing and Business Intelligence at Tecnológico de Monterrey**, I bring an engineering mindset to business problems: define the decision, establish trustworthy data contracts, build the system end to end, validate performance, and communicate measurable impact. I have applied this approach across banking operations, supply-chain analytics, financial machine learning, healthcare service research, CRM, and AI-enabled education.

- **Software engineering:** typed applications, modular architecture, automated testing, API integration, CI workflows, and maintainable documentation.

- **Full stack:** React, Next.js, TypeScript, Python, Firebase, PostgreSQL, REST APIs, and cloud deployments.
- **Product engineering:** user-centered discovery, KPI design, experimentation, security-by-design, and business-value translation.

## Featured Projects

<details open>
<summary><strong>CDD-Mundial — FIFA World Cup 2026 Forecasting System</strong></summary>

<br>

An end-to-end data science system that forecasts the 2026 FIFA World Cup with dynamic Elo ratings, Dixon–Coles modeling, calibrated XGBoost, and tournament-wide Monte Carlo simulation.

| Dimension | Details |
|:---|:---|
| **Stack** | Python · NumPy · pandas · XGBoost · Pandera · Pytest · Matplotlib |
| **Scale** | 48 teams · 104 fixtures · 49,000+ historical matches · thousands of tournament simulations |
| **Performance** | Temporal holdouts, log-loss, Brier/RPS, calibration gates, vectorized simulation |
| **Security** | Gitignored secrets, restricted-source policy, automated secret scanning, immutable raw captures |
| **Impact** | Reproducible live snapshots with full data/model lineage and promotion gates |
| **Repository** | [View source](https://github.com/a01769572-art/Data-Science---World-Cup) |

The system uses strict, coercing Pandera contracts, canonical team identities, deterministic seeds, SHA-256 provenance manifests, and append-only production snapshots. Its ML upgrade is promoted only when it beats the structural baseline on out-of-sample calibration—not because a model is more complex.
